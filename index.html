Battery Management System for Electric Vehicles

MATLAB | Simulink | Stateflow | Embedded Coder | MIL/SIL

Built a multi-rate BMS model with operating modes for initialization, standby, charging, driving, and fault handling. Implemented voltage and temperature protection, current limits, Coulomb-counting SOC estimation, and passive balancing for a three-cell lithium-ion pack. Generated C/C++ code using Embedded Coder and verified model behavior with MIL/SIL test harnesses; the reported comparison showed a 100% signal match.
