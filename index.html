Battery Management

Electric Vehicle Battery Management System

A multi-rate battery management model built with Simulink and Stateflow for monitoring battery state and implementing protective control logic.

  • Implemented safety-disconnect logic and dynamic current limits.
  • Updated current limits every 100 ms and Coulomb-counting SOC every 200 ms.
  • Implemented passive balancing for a three-cell pack when voltage differences exceeded 10 mV.
  • Configured a fixed-step simulation at 0.05 seconds and performed MIL/SIL testing with signal comparison.
  • Generated ERT C/C++ code using Embedded Coder.
Simulink Stateflow BMS SOC Estimation ERT
